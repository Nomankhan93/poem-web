# POEM Logo Branding Patch

This patch replaces placeholder POEM branding with the official logo assets shared by the organization.

## What this patch changes

- adds the official horizontal POEM logo to the public website
- adds the circular POEM emblem for administration branding
- updates the public header to use the official logo
- updates the public footer to use the official logo
- updates the admin sidebar brand block
- refreshes the admin login screen with official POEM branding
- adds reusable `PoemLogo` component
- stores the shared assets in `public/brand/`

## Public branding approach

- **Primary website logo:** horizontal POEM logo
- **Secondary mark/emblem:** circular POEM emblem

## Asset files

- `public/brand/poem-logo-horizontal.jpg`
- `public/brand/poem-logo-emblem.jpg`

## Notes

These files are based on the images provided by POEM and currently include a white background.
For future refinement, request transparent PNG or SVG files from POEM for the cleanest production use on all backgrounds.
